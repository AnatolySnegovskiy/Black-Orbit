## Обзор системы

Система использует **Utility AI** — подход, при котором бот оценивает полезность каждого доступного действия и выбирает лучшее. Это позволяет создавать гибкое и реалистичное поведение без жёстких условий.

## Компоненты системы

### 1. AI (Runtime/AI.cs)
Основной компонент AI. Управляет:
- **Восприятием** (видит ли игрока, угол обзора, препятствия)
- **Навигацией** (движение через NavMeshAgent или Rigidbody)
- **Выбором действий** (оценивает все действия и выполняет лучшее)
- **Чёрной доской** (хранит последнюю позицию игрока, время с последнего обнаружения)

### 2. UtilityAction (ScriptableObjects/Actions/)
Базовый класс для всех действий. Каждое действие:
- Оценивает свою полезность через **факторы**
- Выполняется каждый кадр, пока имеет наивысший приоритет

### 3. UtilityFactor (ScriptableObjects/UtilityFactor.cs)
Фактор для оценки полезности:
- **name** — название для удобства
- **weight** (0-1) — важность фактора
- **curve** — кривая отклика (как входное значение влияет на оценку)

## Доступные действия

### 🚶 PatrolAction — Патрулирование
Бот обходит точки патруля или блуждает случайно.
- **Активируется:** когда игрок не виден и давно не был замечен
- **Параметры:**
  - `waypointTolerance` — радиус достижения точки (м)
  - `wanderRadius` — радиус блуждания без точек (м)
  - `repathInterval` — интервал пересчёта пути (сек)
- **Факторы:**
  - [0] не видит игрока (1.0 если нет LOS)
  - [1] время с последнего обнаружения (0..1)

### 🔍 ExploreAction — Исследование
Бот случайно перемещается по уровню.
- **Активируется:** когда нет контакта с игроком
- **Параметры:**
  - `radius` — радиус исследования (м)
  - `repathInterval` — интервал выбора новой точки (сек)
- **Факторы:**
  - [0] режим ожидания (1.0 если игрока нет)
  - [1] уровень здоровья (0..1)

### 🔎 SearchLastKnownAction — Поиск на последней позиции
Бот идёт туда, где последний раз видел игрока, и сканирует окружение.
- **Активируется:** когда игрок недавно был замечен, но сейчас нет LOS
- **Параметры:**
  - `tolerance` — радиус достижения позиции (м)
  - `scanTime` — время сканирования на месте (сек)
- **Факторы:**
  - [0] игрок замечен недавно (1.0 сразу после потери)
  - [1] нет прямой видимости (1.0 если нет LOS)

### 🏃 PursueAction — Преследование
Бот активно движется к игроку, сокращая дистанцию.
- **Активируется:** когда игрок виден, но дальше желаемой дистанции
- **Параметры:**
  - `desiredRange` — желаемая дистанция до цели (м)
  - `repathInterval` — интервал пересчёта пути (сек)
- **Факторы:**
  - [0] игрок вне желаемой дистанции (0..1)
  - [1] есть прямая видимость (1.0 если видим)

### 🔄 FlankAction — Фланговый манёвр
Бот обходит игрока сбоку или с тыла.
- **Активируется:** когда есть LOS и бот здоров
- **Параметры:**
  - `flankDistance` — дистанция бокового смещения (м)
  - `repathInterval` — интервал пересчёта пути (сек)
  - `minAngle` — минимальный угол отклонения (градусы)
- **Факторы:**
  - [0] есть прямая видимость (1.0 если видим)
  - [1] уровень здоровья (0..1)

### 🛡️ TakeCoverAction — Поиск укрытия
Бот ищет ближайшее укрытие и прячется за ним.
- **Активируется:** при низком здоровье и угрозе
- **Параметры:**
  - `searchRadius` — радиус поиска укрытий (м)
  - `repathInterval` — интервал пересчёта пути (сек)
- **Факторы:**
  - [0] низкое здоровье (0..1)
  - [1] под угрозой (1.0 если игрок видит)
  - [2] игрок близко (0..1)

### 🔫 RangedAttackAction — Дальняя атака
Бот держит оптимальную дистанцию и стреляет.
- **Активируется:** когда игрок на средней дистанции
- **Параметры:**
  - `preferredRange` — предпочтительная дистанция (м)
  - `minRange` — минимальная дистанция, ближе — отступаем (м)
  - `fireCooldown` — кулдаун между выстрелами (сек)
- **Факторы:**
  - [0] находимся на предпочтительной дистанции (0..1)
  - [1] есть прямая видимость (1.0 если видим)
  - [2] уровень здоровья (0..1)

### ⚔️ MeleeAttackAction — Ближняя атака
Бот сближается и наносит удары.
- **Активируется:** когда игрок очень близко
- **Параметры:**
  - `strikeRange` — дистанция удара (м)
  - `swingCooldown` — кулдаун между ударами (сек)
- **Факторы:**
  - [0] игрок близко (0..1)
  - [1] есть прямая видимость (1.0 если видим)

### 🏃‍♂️ RetreatAction — Отступление
Простое отступление от игрока (без поиска укрытия).
- **Активируется:** при низком здоровье и близком враге
- **Параметры:**
  - Автоматически отступает на 3м от текущей позиции
  - Использует `MoveTo()` для совместимости с NavMeshAgent и Rigidbody
- **Факторы:**
  - [0] низкое здоровье (0..1)
  - [1] игрок близко (0..1)

### 🔥 SuppressionFireAction — Подавляющий огонь
Стрельба по последней известной позиции игрока (даже без LOS).
- **Активируется:** когда недавно видели игрока, но сейчас нет прямой видимости
- **Параметры:**
  - `maxTimeSinceSeen` — 3 сек (максимальное время с последнего обнаружения)
  - `fireCooldown` — 0.4 сек (интервал между выстрелами)
  - `minRange` — 5м (минимальная дистанция)
- **Факторы:**
  - [0] недавно видели, но нет LOS (0..1)
  - [1] на подходящей дистанции (0..1)
  - [2] есть союзники рядом (1.0 если есть)

## Система Squad (Отрядов)

### Обзор
Система squad позволяет AI координировать действия в группе, как в F.E.A.R. Отряд автоматически назначает роли и приказывает членам выполнять конкретные действия.

### Быстрая настройка squad:
1. Создайте пустой GameObject → Add Component → **AISquad**
2. Включите `Auto Find Members` и установите `Search Radius`
3. AI в радиусе автоматически присоединятся к отряду
4. Отряд начнёт координировать их действия

### Роли в отряде:
- **Rusher** — агрессивно атакует (Pursue)
- **Flanker** — обходит сбоку (Flank)
- **Suppressor** — стреляет с дистанции (RangedAttack/SuppressionFire)
- **Defender** — держит позицию (TakeCover)

### Подробнее:
См. **[SQUAD_SYSTEM_RU.md](SQUAD_SYSTEM_RU.md)** для полного руководства.

## Пошаговая настройка

### Шаг 1: Настройка префаба AI

1. Добавьте компонент **AI** на префаб (враг/союзник/NPC)
2. Добавьте **NavMeshAgent** (рекомендуется) или оставьте **Rigidbody**
3. Настройте параметры в инспекторе:

#### Фракция и цели
- **Faction** — фракция этого AI (Enemy, Player, Wildlife и т.д.)
- **Hostile Factions** — враждебные фракции (AI будет атаковать их)
- **Allied Factions** — союзные фракции (AI не будет атаковать их)

#### Ссылки
- **Target** — текущая цель (автоматически находится по фракциям)
- **Rb** — автоматически найдётся через GetComponent
- **Agent** — автоматически найдётся через GetComponent

#### Параметры движения
- **Move Speed** — 3-5 м/с (если без NavMeshAgent)

#### Параметры восприятия
- **Detection Range** — 10-15 м (дальность обнаружения)
- **Attack Range** — 2-3 м (для базовых экшенов)
- **Vision Angle** — 110-140° (угол обзора)
- **Vision Range** — 15-20 м (должна быть ≥ detectionRange)
- **Obstacle Mask** — слои стен/препятствий (НЕ включайте слой игрока!)
- **Cover Mask** — слои объектов-укрытий (ящики, стены)

#### Здоровье
- **Health** — 100 (или любое значение 0-100)

#### Патрулирование
- **Patrol Points** — массив точек патруля (опционально)

### Шаг 2: Создание ScriptableObject действий

1. В папке `Assets/Black Orbit/Scripts/AI/ScriptableObjects/Actions/` создайте папку `Data`
2. Создайте нужные действия:
   - ПКМ → Create → AI/Actions → выберите действие
   - Назовите понятно: `Patrol`, `Pursue`, `RangedAttack` и т.д.

### Шаг 3: Настройка факторов для каждого действия

Откройте созданный ScriptableObject и настройте массив **Factors**:

#### Пример: PatrolAction
```
Factors (Size: 2)
├─ [0] notSeeingPlayer
│   ├─ Name: "Не видит игрока"
│   ├─ Weight: 0.7
│   └─ Curve: Linear (0,0) → (1,1)
└─ [1] timeSinceSeen
    ├─ Name: "Время с последнего обнаружения"
    ├─ Weight: 0.3
    └─ Curve: S-образная (медленный рост, затем резкий)
```

#### Пример: TakeCoverAction
```
Factors (Size: 3)
├─ [0] lowHealth
│   ├─ Name: "Низкое здоровье"
│   ├─ Weight: 0.5
│   └─ Curve: Выпуклая (быстрый рост при низком HP)
├─ [1] underThreat
│   ├─ Name: "Под угрозой"
│   ├─ Weight: 0.3
│   └─ Curve: Linear
└─ [2] closeToPlayer
    ├─ Name: "Игрок близко"
    ├─ Weight: 0.2
    └─ Curve: Linear
```

#### Типы кривых:
- **Linear** — прямая зависимость
- **S-образная** — пороговое поведение (сначала слабо, потом резко)
- **Выпуклая** — быстрый рост в начале
- **Колокол** — оптимум в середине (для дистанций)

### Шаг 4: Назначение действий на AI

1. Выберите префаб AI
2. В компоненте **AI** → **Actions** укажите размер массива
3. Перетащите созданные ScriptableObject'ы в слоты

**Рекомендуемый набор:**
1. Patrol
2. Explore
3. SearchLastKnown
4. Pursue
5. Flank
6. TakeCover
7. RangedAttack (или MeleeAttack)
8. Retreat

### Шаг 5: Настройка NavMesh

1. Window → AI → Navigation
2. Отметьте объекты уровня как **Navigation Static**
3. Настройте параметры NavMesh (Agent Radius, Height)
4. Нажмите **Bake**

### Шаг 6: Настройка слоёв

1. Edit → Project Settings → Tags and Layers
2. Создайте слои:
   - `Player` — для игрока
   - `Enemy` — для врагов
   - `Cover` — для укрытий
   - `Obstacle` — для стен/препятствий
3. Назначьте слои объектам
4. В **EnemyAI**:
   - **Obstacle Mask** = Obstacle (НЕ Player!)
   - **Cover Mask** = Cover

## Типичные ошибки и решения

### ❌ Бот не видит игрока
- Проверьте `visionAngle` и `visionRange`
- Убедитесь, что слой игрока **НЕ** в `obstacleMask`
- Проверьте, что между ботом и игроком нет объектов на слое `obstacleMask`

### ❌ Бот не двигается
- Проверьте, что `NavMeshAgent` настроен и уровень запечён (Bake)
- Убедитесь, что бот стоит на NavMesh (синяя зона в Scene View)
- Если используете Rigidbody, проверьте `moveSpeed`

### ❌ Бот не находит укрытие
- Убедитесь, что объекты-укрытия на слое `coverMask`
- Проверьте `searchRadius` в TakeCoverAction (должен быть достаточно большим)
- Укрытия должны иметь Collider

### ❌ Бот застревает в одном действии
- Проверьте веса и кривые факторов — возможно, одно действие всегда имеет высокий приоритет
- Убедитесь, что факторы правильно нормализованы (0..1)
- Логи выбора действий уже включены в AI.cs

### ❌ Бот слишком агрессивный/пассивный
- Настройте веса факторов:
  - Увеличьте вес `health` в атакующих действиях для агрессивности
  - Увеличьте вес `lowHealth` в TakeCover/Retreat для осторожности
- Измените кривые: S-образная для резких переходов, линейная для плавных

## Интеграция с системой оружия

### Автоматическая интеграция с WeaponSystem

`RangedAttackAction` автоматически использует вашу `WeaponSystem` для стрельбы!

#### Настройка оружия AI:

1. **Добавьте компонент `AIWeaponHandler`** на префаб AI
2. **Настройте параметры:**
   - `Weapon Data` — перетащите `WeaponScriptableObject` (например, AssaultRifle)
   - `Muzzle Point` — точка выстрела (опционально, создастся автоматически)
   - `Auto Initialize` — оставьте включённым

#### Как это работает:

```csharp
// RangedAttackAction автоматически находит AIWeaponHandler и вызывает:
weaponHandler.TryFire();
```

`AIWeaponHandler` инициализирует `StandardWeapon` с вашими данными оружия и управляет стрельбой, перезарядкой и боеприпасами.

#### Альтернативный способ:

Если вы хотите использовать свой компонент оружия:
1. Реализуйте интерфейс `IWeapon` на вашем компоненте
2. Добавьте компонент на врага
3. `RangedAttackAction` автоматически найдёт его через `TryGetComponent<IWeapon>`

#### Для ближнего боя:

`MeleeAttackAction` пока использует Debug.Log. Вы можете интегрировать свою систему ближнего боя аналогично:
```csharp
if (enemy.TryGetComponent<MeleeWeaponHandler>(out var melee))
{
    melee.Strike();
}
```

## Советы по балансировке

### Для агрессивного бота:
- Увеличьте вес факторов атаки
- Уменьшите `preferredRange` в RangedAttack
- Увеличьте `visionAngle` и `visionRange`

### Обратная совместимость:

- Старые `AttackAction` и `RetreatAction` работают
- Можно использовать без `NavMeshAgent` (через Rigidbody)
- Можно использовать без `AIWeaponHandler` (будет Debug.Log)
- Свойство `player` доступно для совместимости (алиас для `target`)

### Для разведчика:
- Увеличьте вес Patrol и Explore
- Уменьшите `visionAngle` (узкий обзор)
- Увеличьте `wanderRadius` и `radius`

### Для снайпера:
- Увеличьте `preferredRange` в RangedAttack (20-30м)
- Увеличьте `fireCooldown` (1.0-2.0 сек)
- Уменьшите `visionAngle` (60-90°, узкий обзор)

## Дополнительные возможности

### Создание своего действия

1. Создайте новый класс, наследующий `UtilityAction`:

```csharp
using Black_Orbit.Scripts.AI.Runtime;
using UnityEngine;

namespace Black_Orbit.Scripts.AI.ScriptableObjects.Actions
{
    [CreateAssetMenu(menuName = "AI/Actions/MyCustomAction", fileName = "MyCustomAction")]
    public class MyCustomAction : UtilityAction
    {
        [Header("Параметры")]
        [Tooltip("Описание параметра")]
        public float myParameter = 5f;

        public override float[] GetInputs(AI ai)
        {
            // Верните массив входных значений (0..1) для факторов
            float input1 = /* ваша логика */;
            float input2 = /* ваша логика */;
            return new[] { input1, input2 };
        }

        public override void Execute(AI ai)
        {
            // Ваша логика выполнения действия
            Debug.Log("Выполняется моё действие!");
        }
    }
