# Debug-визуализация AI

## Обзор

AI автоматически отображает конус зрения и другую отладочную информацию в Scene View при выборе объекта.

## Как использовать

1. Запустите игру в Unity Editor
2. Откройте Scene View
3. Выберите AI объект в иерархии
4. Визуализация появится автоматически

---

## Элементы визуализации

### 🔺 Конус зрения

**Цвет зависит от состояния:**
- 🟡 **Жёлтый (полупрозрачный)** — цель НЕ видна
- 🔴 **Красный (полупрозрачный)** — цель ВИДНА (Line of Sight)

**Что показывает:**
- Угол обзора (`visionAngle`)
- Дальность зрения (`visionRange`)
- Границы конуса (жирные линии)

### 🔵 Дальность обнаружения

**Синяя окружность** вокруг AI
- Показывает `detectionRange`
- Радиус, в котором AI ищет цели

### 🔴 Дальность ближней атаки

**Красная окружность** вокруг AI
- Показывает `meleeAttackRange`
- Используется для ближнего боя (MeleeAttack)
- Берсерки: 3-5м, обычные: 2м

### 🟠 Дальность дальней атаки

**Оранжевая окружность** вокруг AI
- Показывает `rangedAttackRange`
- Используется для стрельбы (RangedAttack)
- Снайперы: 100-300м, обычные: 20-30м

### 🎯 Цель

**Если AI видит цель:**
- 🔴 **Красная линия** от AI к цели
- 🔴 **Красная сфера** на позиции цели

**Последняя известная позиция:**
- 🟣 **Фиолетовая сфера** на последней позиции
- 🟣 **Фиолетовая линия** от AI к позиции

### 🔵 Направление взгляда

**Синяя стрелка** от головы AI
- Показывает `transform.forward`
- Длина: 2 метра

### 📊 Информация над головой

**Текст над AI (2.5м):**
```
Enemy                    ← Фракция
HP: 100                  ← Здоровье
LOS: ✓                   ← Line of Sight (видит/не видит)
Time: 2.3s               ← Время с последнего обнаружения
Melee: 2m | Range: 25m   ← Дальности атак
Action: Pursue           ← Текущее действие
```

**Цвет текста:**
- 🔴 **Красный** — видит цель
- ⚪ **Белый** — не видит цель

## Примеры использования

### Отладка обзора

**Проблема:** AI не видит игрока

**Решение:**
1. Выберите AI в Scene View
2. Проверьте конус зрения (жёлтый/красный)
3. Убедитесь, что игрок внутри конуса
4. Проверьте, нет ли препятствий (красная линия должна быть видна)

### Настройка дальностей

**Задача:** Настроить оптимальные дальности

**Действия:**
1. Выберите AI
2. Посмотрите на окружности (синяя и красная)
3. Измените `detectionRange` и `attackRange` в Inspector
4. Визуализация обновится в реальном времени

### Проверка действий

**Задача:** Понять, какое действие выполняется

**Действия:**
1. Запустите игру
2. Выберите AI
3. Смотрите на текст "Action: ..." над головой
4. Действие меняется в реальном времени

## Цветовая схема

| Элемент | Цвет | Значение |
|---------|------|----------|
| Конус зрения | 🟡 Жёлтый | Цель не видна |
| Конус зрения | 🔴 Красный | Цель видна |
| Detection Range | 🔵 Синий | Радиус обнаружения |
| Attack Range | 🔴 Красный | Радиус атаки |
| Луч к цели | 🔴 Красный | Прямая видимость |
| Последняя позиция | 🟣 Фиолетовый | Где видели цель |
| Направление | 🔵 Синий | Куда смотрит AI |
| Текст (видит) | 🔴 Красный | Line of Sight = true |
| Текст (не видит) | ⚪ Белый | Line of Sight = false |

## Производительность

### В Editor:
- ✅ Визуализация работает только в Scene View
- ✅ Не влияет на Game View
- ✅ Отрисовка только для выбранных объектов

### В Build:
- ✅ Gizmos автоматически отключаются
- ✅ Никакого влияния на производительность
- ✅ Код обёрнут в `#if UNITY_EDITOR`

## Отключение визуализации

### Временно:
- Просто не выбирайте AI в иерархии

### Полностью:
Закомментируйте метод `OnDrawGizmosSelected()` в `AI.cs`:

```csharp
// void OnDrawGizmosSelected()
// {
//     ...
// }
```

## Дополнительные возможности

### Gizmos в Game View

Если нужно видеть Gizmos в Game View:
1. Нажмите на кнопку "Gizmos" в правом верхнем углу Game View
2. Включите нужные элементы

### Постоянная визуализация

Замените `OnDrawGizmosSelected()` на `OnDrawGizmos()`:
```csharp
void OnDrawGizmos() // Всегда видно
{
    // ... тот же код
}
```

⚠️ **Внимание:** Это может снизить производительность Editor при большом количестве AI!

## Советы

### Для отладки восприятия:
- Смотрите на цвет конуса (жёлтый/красный)
- Проверяйте красную линию к цели
- Следите за "LOS: ✓/✗" в тексте

### Для настройки дальностей:
- Используйте окружности как ориентир
- Detection Range (синяя) должна быть ≥ Vision Range
- Attack Range (красная) для ближнего боя

### Для проверки действий:
- Текст "Action: ..." показывает текущее действие
- Меняется в реальном времени
- Помогает понять логику AI

## Частые вопросы

### Q: Визуализация не появляется?
**A:** Убедитесь, что:
- AI выбран в иерархии
- Scene View открыт
- Gizmos включены (кнопка в Scene View)

### Q: Конус всегда жёлтый?
**A:** Это значит AI не видит цель. Проверьте:
- Цель в радиусе `visionRange`
- Цель в угле `visionAngle`
- Нет препятствий (`obstacleMask`)

### Q: Текст не отображается?
**A:** Текст работает только в Editor. В Build он автоматически отключается.

### Q: Как изменить цвета?
**A:** Отредактируйте метод `OnDrawGizmosSelected()` в `AI.cs` и измените значения `Gizmos.color`.
