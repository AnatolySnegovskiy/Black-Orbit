# Руководство по Faction Editor

## Открытие редактора

**Tools → Faction → Faction Editor**

## Интерфейс

### Левая панель - Список фракций

- **Обновить** — перезагрузить список фракций
- **Создать** — создать новую фракцию
- Список всех фракций с цветными индикаторами
- Статистика (количество фракций)

### Правая панель - Детали фракции

**Основная информация:**
- Название фракции
- Цвет (для визуализации)
- Иконка (опционально)
- Описание

**Отношения:**
- Список всех отношений с другими фракциями
- Слайдер для настройки (-1 ... 1)
- Текстовое описание отношения
- Кнопки добавления/удаления

**Действия:**
- **Сохранить изменения** — сохранить фракцию
- **Удалить фракцию** — удалить фракцию
- **Синхронизировать все** — синхронизировать отношения (двусторонние)

### Нижняя панель - Матрица отношений

Визуальная таблица всех отношений между фракциями:
- **Строки** — фракция 1
- **Столбцы** — фракция 2
- **Цвет ячейки** — уровень отношений

**Легенда:**
- 🟥 Тёмно-красный — Лютый враг (-1.0 ... -0.8)
- 🟧 Красный — Враг (-0.8 ... -0.5)
- 🟨 Оранжевый — Недружелюбный (-0.5 ... -0.3)
- ⬜ Белый — Нейтральный (-0.3 ... 0.3)
- 🟩 Светло-зелёный — Дружелюбный (0.3 ... 0.5)
- 🟢 Зелёный — Друг (0.5 ... 0.8)
- 🟢 Тёмно-зелёный — Лучший друг (0.8 ... 1.0)
- ⬛ Серый — Сама с собой (1.0)

## Быстрый старт

### Создание стандартных фракций

**Tools → Faction → Create Default Factions**

Создаёт 6 фракций с настроенными отношениями:
- **Player** (синий) — игрок
- **Enemy** (красный) — враги
- **Wildlife** (коричневый) — дикая природа
- **Guards** (тёмно-синий) — стража
- **Bandits** (тёмно-красный) — бандиты
- **Civilians** (серый) — мирные жители

### Создание своей фракции

1. Откройте Faction Editor
2. Нажмите **"Создать"**
3. Введите название
4. Настройте параметры в правой панели
5. Добавьте отношения через **"Добавить отношение"**
6. Нажмите **"Сохранить изменения"**

---

## Работа с отношениями

### Добавление отношения

1. Выберите фракцию
2. Нажмите **"Добавить отношение"**
3. Выберите фракцию из меню
4. Настройте слайдер (-1 ... 1)
5. Сохраните

### Синхронизация отношений

Кнопка **"Синхронизировать все"** делает отношения двусторонними:
- Если Player → Enemy = -1.0
- То Enemy → Player = -1.0

### Удаление отношения

Нажмите **"X"** рядом с отношением.

## Советы

### Цветовая схема

Используйте логичные цвета:
- 🔵 Синий — союзники игрока
- 🔴 Красный — враги игрока
- 🟡 Жёлтый — нейтральные/торговцы
- 🟢 Зелёный — природа/животные
- ⚪ Серый — мирные жители

### Балансировка отношений

- **-1.0 ... -0.8** — только для главных антагонистов
- **-0.8 ... -0.5** — обычные враги
- **-0.5 ... -0.3** — потенциальные враги
- **-0.3 ... 0.3** — нейтральные (по умолчанию)
- **0.3 ... 0.5** — дружелюбные NPC
- **0.5 ... 0.8** — союзники
- **0.8 ... 1.0** — близкие друзья/компаньоны

### Синхронизация

Всегда синхронизируйте отношения для симметричности:
- Если A враг B, то B враг A
- Исключение: асимметричные отношения (редко)

## Матрица отношений

### Чтение матрицы

```
        Pla  Ene  Wil  Gua
Player  =   -1.0  0.0  0.5
Enemy  -1.0  =   -0.5 -0.8
Wild    0.0 -0.5  =    0.0
Guards  0.5 -0.8  0.0  =
```

- **Строка** = фракция, которая оценивает
- **Столбец** = фракция, которую оценивают
- **=** = сама с собой (всегда 1.0)

### Использование матрицы

Матрица помогает:
- Быстро увидеть все отношения
- Найти несимметричные отношения
- Проверить баланс фракций
- Визуализировать сложные связи

## Частые вопросы

### Q: Где хранятся фракции?
**A:** `Assets/Black Orbit/GameData/Factions/`

### Q: Можно ли изменить путь?
**A:** Да, измените константу `FACTIONS_PATH` в `FactionEditor.cs`

### Q: Что делать если фракция не появляется?
**A:** Нажмите кнопку **"Обновить"** в левой панели

### Q: Как удалить все фракции?
**A:** Удалите папку `GameData/Factions/` в Unity Project

### Q: Можно ли создать фракцию вручную?
**A:** Да, через Create → Faction System → Faction, но Editor удобнее
